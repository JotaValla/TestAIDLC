# Visión

Una biblioteca de barrio que presta libros a sus socios sin perder el rastro de quién tiene qué.

> Proyecto de juguete para probar el flujo de trabajo. El "dueño de producto" lo juega uno de los dos devs.

## Metas de negocio

| Id | Meta | Indicador |
|----|------|-----------|
| M1 | Saber siempre dónde está cada libro | 0 libros "perdidos" en el inventario mensual |
| M2 | Que los socios devuelvan a tiempo | % de devoluciones tardías < 10 % |
| M3 | Código fácil de mantener (meta transversal) | Toda funcionalidad tiene pruebas automáticas |
